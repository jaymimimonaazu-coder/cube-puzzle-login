# 🔐 cube-puzzle-login

3D立方体を**からくり箱のように正しい手順で開く**と認証成功になる、パズルログインの概念実証(PoC)です。
Three.js 製・単一HTMLで動きます。

## デモの動き

1. 光っているパーツ(ハンドル)をクリックすると、木箱のパーツがスライドして開く
2. **正しい順番**（右パネル → 前バー → 天板 → 中央キー）で開くと解錠 → **「認証成功」**
3. 順番を間違えると箱が揺れて**最初にリセット**（からくり箱の物理的ブロックを再現）
4. 画面ドラッグで視点回転、ホイールでズーム

## 使い方

`index.html` をブラウザで開くだけです（Three.js は CDN 読み込みのため、ネット接続が必要）。

```bash
open index.html            # macOS
# または簡易サーバー経由
python3 -m http.server 8000
# → http://localhost:8000
```

## 認証設計の考え方（重要）

このデモは**解錠判定をブラウザ側で行っている**ため、そのままでは本番のログインに使えません。
実運用する場合は下記の設計にしてください。

| 項目 | 設計 |
|---|---|
| 判定場所 | **必ずサーバー側**。「解いた状態」の文字列をハッシュ化して送信し、サーバーで照合 |
| 位置づけ | 単独パスワードではなく **多要素認証(MFA)の1要素** として利用 |
| エントロピー | 手順(順序)を秘密にする＝組み合わせ数を稼ぐ。ステップ数を増やすほど強くなる |
| リプレイ対策 | サーバー発行の nonce を混ぜてハッシュ化（本デモの `karakuri-v1` 部分に相当） |
| レート制限 | 総当たり対策として試行回数制限・遅延を入れる |

デモでは解錠時に `SHA-256(solution + version)` を計算して表示しています。
これが「サーバーに送って照合するハッシュ」のイメージです。

### 認証理論上の位置づけ

「立方体を正しい手順で解く」は **知識ベース認証（何を知っているか）** に分類され、
Androidのパターンロックや PassPoints などの**グラフィカルパスワード**の一種にあたります。

- **メリット**: 直感的で記憶しやすい、ショルダーハック（覗き見）に多少強い
- **注意点**: 手順が短いとエントロピーが低くパスワードとして弱い → 必ずMFAの1要素として使う

## 技術構成

| 要素 | 技術 |
|---|---|
| 3D表示・操作 | Three.js 0.160（`WebGLRenderer` / `OrbitControls` / `Raycaster`） |
| 手順ゲート | 現在ステップを状態管理し、正しい順以外のクリックは全リセット |
| アニメーション | イージング(`easeOutCubic`)付きの自前tween |
| ハッシュ | ブラウザ標準の `crypto.subtle.digest('SHA-256', ...)` |

依存パッケージはなし。`index.html` 単体で完結しています（Three.js は importmap + CDN）。

## カスタマイズ

`index.html` 内の `makePart({...})` の**呼び出し順が解錠手順**です。

```js
// ステップ1: 右パネル（+X方向へスライド）
makePart({ size: [0.25, 2.2, 2.2], pos: [1.22, 0, 0], axis: [1, 0, 0], dist: 1.6, color: 0x9c6b3a });
```

| パラメータ | 意味 |
|---|---|
| `size` | パーツの大きさ [x, y, z] |
| `pos` | 閉じた状態の位置 |
| `axis` | 開く方向の単位ベクトル |
| `dist` | 開く距離 |
| `color` | 木材の色 |

呼び出し順を入れ替えれば「正解の手順」も変わります。パーツを追加すればステップ数を増やせます
（HUDの `<ul class="steps">` の項目も合わせて増やしてください）。
