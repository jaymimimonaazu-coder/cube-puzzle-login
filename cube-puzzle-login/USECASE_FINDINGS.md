# 用途仮説の検証結果 — Codex による外部レビュー

Claude が提案した用途仮説（U1〜U12）を Codex に検証させた結果と、その受け入れ判断の記録。

## 結論

**独立した認証製品としての事業化は非推奨。**
体験型コンテンツ（展示会・脱出ゲーム）としての小規模受託のみ、検証する価値がある。

Claude が「最有力」と提示した **VR用途は、根拠の2本柱が両方とも否定された**。

## 判定一覧

| # | Claudeの主張 | Codex判定 | 備考 |
|---|---|---|---|
| U1 | VRの文字入力は破綻している | **疑問**（誇張） | 不便なのは事実だが「破綻」は言い過ぎ。VR内物理キーボードでデスクトップの約60%速度が出る |
| **U2** | 共有VRではパスキーが構造的に使えない | **誤り** | HoloLensは複数ユーザー・Entra・FIDO2対応。MetaはQuestからスマホのパスキーを使うクロスデバイス認証を公開済み。Quest for Business に Shared Mode あり |
| **U3** | VRでは覗き見の弱点が消える | **誤り** | キャスト/ミラー表示・録画・配信・管理者モニター・コントローラーや腕の軌跡・視線・タップ音が残る |
| U4 | WebXR対応は1〜2日 | **疑問** | 表示だけの試作なら1〜3日。コントローラーで動くデモ1〜2週間。複数機種対応3〜8週間 |
| U5 | 製造業VR教育に本人記録の需要がある | 妥当（но必要性は疑問） | 需要は実在。ただし社員証・SSO・QR・NFC・FIDO2で足りる。法定教育では社員IDとの結び付きの方が説明責任を果たしやすい |
| U6 | 低学年に絵パスワード需要が実証済み | **疑問** | 「実証済み」の資料は確認できず。Apple Shared iPad は低年齢向けに4桁/6桁PINを提供。12点は短いPINより認知負荷が高い可能性 |
| U7 | 視線入力向けの競合がほぼ不在 | **誤り** | gaze系グラフィカル認証、PassWalk（平均約8秒・観察攻撃成功率1.1%）等が存在 |
| U8 | シードフレーズの代替になる | **誤り（最も危険）** | 41.44bitは全く不足。BIP39は128〜256bit。資産喪失に直結するため製品化すべきでない |
| U9 | 危険操作の確認ゲートになる | **疑問** | 確認ダイアログ・対象名再入力・Undo・遅延実行の方が簡単。送金では取引内容と認証の暗号学的結合が必要で、再入力だけでは改変を防げない |
| U10 | 認知機能スクリーニングに転用できる | **現状では誤り** | 妥当性の科学的根拠なし。日本で「MCI判定」と表示すれば薬機法上のプログラム医療機器に該当する可能性。PMDA事前相談が必要 |
| U11 | 96設備のダッシュボードになる | **誤り** | 奥面が隠れ回転が必要。警報見落とし・比較困難・ラベル可読性低下。2Dグリッド/表/ヒートマップが適する |
| **U12** | 展示会・脱出ゲームで受託販売できる | **妥当（最有力）** | 認証強度が商品価値でないため成立。20〜50万円は「テンプレート流用・1機種・色/ロゴ変更・オフライン」の範囲なら現実的 |

## 先行技術（最重要）

Codex の指摘:

- **3Dパスワードは新規概念ではない。** Alsulaiman & El Saddik が2006年に3D仮想環境での認証方式を発表
- **EP2852912B1 が「各面にグリッドを持つ立方体」をグラフィカルパスワードの表示物として明示**（Codex 報告）
- 関連: US9589125B2（3D Pass-Go）、US10341333B2（Multi-dimensional password）、US20210273944A1（VR authentication）

### 検証状況（正直な記録）

`patents.google.com` はこの実行環境のネットワークポリシーで遮断されており、**EP2852912B1 の内容を直接確認できていない**。
Web検索では以下の周辺特許の実在を確認した（EP2852912 自体は検索結果に出ず）:

- CA2495450A1 / US20060174339A1 — グリッド交点選択によるグラフィカルパスワード
- US20160188865A1 — 3D Pass-Go
- AU2014225864B2 — 立方体型GUI（各面にファイル/アプリを配置し回転して閲覧）

**判断**: 個別特許の確認は未了だが、**この領域に先行技術が密集していることは確認できた**。
「新規性のある発明」として扱うのは危険であり、事業化前に弁理士による FTO（Freedom to Operate）調査が必須。
広い概念での新規特許取得も difficult と考えるべき。

## Claude の誤りの原因

| 誤り | 原因 |
|---|---|
| U2「パスキーが構造的に使えない」 | **既存製品の対応状況を調べずに断定した**。HoloLens/Quest/PICO の共有端末対応を確認していなかった |
| U3「覗き見が消える」 | **キャスト・録画・腕の軌跡という明白な経路を見落とした**。「ヘッドセット内は見えない」だけで結論を出した |
| U7「競合が不在」 | 調べずに「不在」と断定した |
| U11「ダッシュボードに使える」 | 3D表示の欠点（奥面が見えない）を自分で実装時に対処していたにもかかわらず、用途提案では考慮しなかった |

共通する原因は **市場・既存製品・先行研究を調べずに推論だけで断定したこと**。
依頼書にその旨を明記して検証を依頼したことで、4件の誤りが検出された。

## 受け入れる結論と次の行動

### 商品としての位置づけを変更する

```
避ける: 「次世代3D認証システム」
推奨:   「立方体型インタラクティブパズル」
        「Web展示会向け3Dロック体験」
        「脱出ゲーム向けWebXRギミック」
```

### Codex 提示の Go/No-Go 基準（採用）

1. 10〜20人で翌日・1週間後の再現率を測る
2. PIN・2Dパターン・Cube を比較する
3. 既存顧客3社へ30〜50万円で提案する
4. 1社も有償PoCへ進まなければ**認証用途は終了**
5. 展示・ゲーム用途に反応があればテンプレート商品化
6. **特許を主張しない**。販売前に FTO の専門相談を受ける

### GitHub 公開の扱い

Codex 判定は「研究・デモプロジェクトとしては価値あり」。
ポートフォリオ／セキュリティ教材／営業デモとしての公開は妥当。
ただし **「次世代認証」と称さない**こと。
