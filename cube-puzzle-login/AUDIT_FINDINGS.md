- pytest **50件すべて合格**（監査前は16件）

## 修正の要点

| ID | 修正内容 |
|---|---|
| H-1 / M-3 | 検証の**前に**試行枠を原子的に消費する方式へ。`BEGIN IMMEDIATE` + 相対UPDATE + プロセス内直列化 |
| H-2 | `enroll` は新規のみ（既存は409）。変更は `/api/reenroll`、削除は `/api/forget` でセッション必須 |
| H-3 | `estimate_bits` / `MIN_ENROLL_BITS` を**廃止**。`find_weak_patterns()` による規則検査に置換し、bit値をAPIから削除。保証が必要な場合用に `generate_random()` を追加 |
| M-1 | 本文4KB上限のミドルウェア + pydanticで面数を固定 |
| M-2 | ロック中もダミー検証で同じ時間を消費。既定では応答からロック状態を判別不可 |
| M-4 | Argon2 の同時実行を4に制限し、飽和時は503 |
| M-5 | `/api/status` を**廃止**。画面のモードは利用者が選択する方式に変更 |
| M-6 | IP単位のレート制限（30回/5分）を併用 |
| L-1 | セッションをDB保存（トークンはハッシュ化・1時間期限・失効可能）。資格情報変更で全失効 |
| L-2 | pydantic を `strict=True` + `extra="forbid"` に |
| L-3 | 失敗メッセージから残り試行回数を削除 |
| L-4 | CORS許可元を環境変数で明示（既定は同一オリジンのみ） |

## 主張の訂正（architecture.json に反映済み）

- 「オンライン1700万年」は**H-1修正後に初めて有効**。監査前は無効だったことを明記
- 全探索時間は**最悪と平均を併記**（平均は最悪の半分）
- Argon2id の 2,000 H/s は**未実証の仮定**であることを明記
- 41.44bit は**一様ランダム選択時の理論値**であり、利用者が選ぶ場合の実効値ではないことを明記
